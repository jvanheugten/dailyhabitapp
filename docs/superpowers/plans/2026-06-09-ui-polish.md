# UI Polish & Desktop Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Center the app at 430px on desktop and apply a consistent design system (CSS variables, standard card style, typography scale) across all screens.

**Architecture:** Pure CSS changes — no logic or JSX modifications except where a CSS class is renamed or added. All changes are in `.module.css` files and `App.module.css`. No new dependencies.

**Tech Stack:** React 18 + Vite, CSS Modules, existing CSS variable design system (`--surface`, `--border-subtle`, `--text-muted`, `--text-dim`, `--green`, `--accent`, `--radius`, `--radius-sm`)
